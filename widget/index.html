Home Screen widget

Current weather, the next-2-hours rain outlook and the coming hours, right on your Home Screen or Lock Screen. It uses the free Scriptable app.

  1. Tap Copy script above.
  2. Open Scriptable and tap + (top right).
  3. Tap the empty editor, then Paste.
  4. Tap the title at the top and name it Weather.
  5. Tap ▶︎ (bottom right) once, allow location, and pick a size to preview. Then tap Done.
  6. Go to the Home Screen, long-press an empty spot, tap Edit → Add Widget → Scriptable, and choose small, medium or large.
  7. Long-press the new widget → Edit Widget → set Script to Weather.

Options

In Edit Widget, the Parameter field picks the place:

  • empty: your current location
  • a town name, for example Berlin
  • coordinates, for example 52.52,13.41

For the Lock Screen: long-press the Lock Screen → Customize → Lock Screen → tap the widget area → Scriptable, then tap the added widget and choose Weather.

The widget refreshes about every 15–30 minutes (iOS decides exactly when). Tapping it opens this app in Safari. It updates itself automatically when the app is updated, so you only need to paste the script once.
